WithViewer利用規約

プライバシーポリシー

運営者：Flateight ／ 最終更新：2026年10月9日

現在は開発・検証版です。機密情報・第三者の個人情報を含む会議での利用は、所属組織のルールと外部AIへの送信条件を確認したうえで判断してください。

Flateight（以下「運営者」）は、WithViewerで取り扱う情報、その利用目的、保存と削除の方法を以下のとおり説明します。

1. 取り扱う情報と利用目的

情報利用目的
Googleアカウントの識別情報・メールアドレス、Firebaseの認証情報ログイン、利用権限の確認、Drive接続アカウントとの一致確認。ログインに用いるGoogle/Firebaseは表示名・プロフィール画像等を処理する場合があります。WithViewerは認証と本人確認に必要な情報を使用します。
利用者が共有したタブ・画面の音声、選択した映像の静止画、会議名、文字起こし、会議メモ会議の記録、検索、文字起こし、資料の読取り、要約、議事録の作成。
相談の入力、マイク音声、AIの回答、相談履歴会議を踏まえた音声・テキスト相談。相談履歴は会議で実際に発言された内容と区別して保存します。
Driveの認可情報、選択したフォルダのID・名称、保存ファイルのID利用者のDriveへのバックアップ、同じ会議ファイルの更新、フォルダ作成。
IPアドレス、通信・認証・エラー等の技術情報配信、認証、外部APIの処理、障害対応、不正利用の防止。配信・認証等の提供事業者が処理する場合があります。

2. AI処理と外部サービスへの送信

文字起こしでは録音音声、映像の読取りでは静止画、要約・議事録では対象の会議文章をGoogleのGemini APIへ送信します。相談では質問・相談履歴・必要な会議文脈を送信し、映像を有効にした場合には静止画も送信することがあります。音声相談ではマイク音声を送信します。公開版のAPI処理はCloudflareを経由し、音声相談の通信は認可取得後にGoogleへ直接接続します。

Google側でのAI入力・出力の扱いは、利用するAPIプロジェクトの課金状態やGoogleの条件により異なります。Geminiの無償サービスでは入力・出力がサービス改善等に利用され、人による確認の対象となる場合があります。有償サービスではGoogleは入力・出力を製品改善に利用しないと定めていますが、安全性等のため一定期間処理・記録する場合があります。現在の開発版は課金・保持条件の最終確認前であり、「AIの学習に一切利用されない」と保証するものではありません。詳細はGemini API追加利用規約を確認してください。

認証はGoogle/Firebase、配信とAPI処理はCloudflare、Drive保存とフォルダ選択はGoogle Drive API・Google Pickerを利用します。これらの事業者が国外で情報を処理する場合があります。各事業者の取扱いはGoogleのプライバシーポリシー、Cloudflareのプライバシーポリシーも参照してください。

3. Google Driveのアクセス権限

Drive接続は任意です。GoogleログインだけではDrive保存を開始しません。接続時に本人確認のためのopenid・emailと、アプリで作成または利用者が選択したファイル・フォルダにアクセスするdrive.file権限を要求します。Drive全体への包括的なアクセス権限は要求しません。

利用者が選んだ保存先に会議一式ZIPを作成し、その会議の記録が更新された場合は同じファイルを更新します。利用者の操作により新規フォルダも作成します。Drive上の任意の文書を収集したり、保存済みファイルを自動削除したりする機能はありません。ZIP復元は、利用者がDriveからダウンロードして指定したファイルを端末内で読み込む方式です。

運営者はGoogle APIから得た情報を本ポリシーに記載した機能のために使用し、販売、広告配信、独立した一般目的AIモデルの学習のために使用しません。Google APIから受領した情報の使用および他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

4. 保存場所・保持期間

会議記録・音声・画像・相談履歴・議事録は、基本的に利用したブラウザーのIndexedDBに保存します。運営者のデータベースへ会議の原本を長期保管する設計ではありません。ブラウザーの保存容量、サイトデータの消去、端末の故障等により失われる場合があります。ログアウトだけでは会議記録を削除しません。同じ端末・ブラウザーを共有する場合、他の利用者がローカルの記録を閲覧できる可能性があります。

Drive保存を有効にした場合は、利用者自身のGoogle DriveにZIPを保存します。アプリから自動削除しません。Driveでの保持・共有範囲・削除は利用者の設定とGoogleの提供条件に従います。自動保存はページが開いている間に行い、完了表示が出るまで保存は確定しません。

ログイン状態はブラウザーのセッション保存、Drive保存先・自動保存設定はローカルストレージを使用します。Driveの長期認可情報は暗号化したSecure・HttpOnly Cookieに保存し、Cookieの有効期間は最長180日です。Google側の失効や認可取消しにより、それより早く再接続が必要になる場合があります。認可処理の状態確認用Cookieは10分で失効します。外部事業者のログ・認証情報等の保持は各事業者の条件によります。

5. 削除・連携解除

  • 端末内の記録を削除する場合は、必要なバックアップを確保したうえでブラウザーの当該サイトの保存データを削除してください。この操作ではDriveのZIPは削除されません。
  • Driveの保存データはGoogle Driveで削除してください。必要に応じてゴミ箱も管理してください。この操作では端末内の記録は削除されません。
  • アプリの「連携を解除」は、このブラウザーのDrive接続情報を削除し、自動保存を停止します。Google側の許可自体を取り消す場合はGoogleアカウントの接続管理から操作してください。
  • 認証アカウント情報の削除や運営者が保有する情報に関する開示・訂正等の相談窓口は、一般公開前に以下へ掲載します。

6. 安全管理と変更

公開版のAPIでは認証・利用権限を確認し、HTTPSで通信します。Driveの長期認可情報は暗号化し、OAuthクライアントのSecretをブラウザーへ渡しません。運営者は機能や情報の取扱いを変更する場合、本ページを更新します。Googleデータの利用目的やアクセス範囲を拡大する場合は、必要な説明と認可を改めて行います。
