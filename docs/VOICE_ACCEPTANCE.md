# 音声対話の実機受け入れ試験

現在は未実施です。APIキーをローカルに設定してから、開発計画T1〜T9を以下の手順で確認します。キー・会議の秘密情報を試験結果へ記載しません。

## 準備

- WindowsのChrome／Edge、会議タブの音声共有、ヘッドホン、利用者用マイクを用意する。
- 実際の機密会議を使わず、発言内容と時刻が分かる試験動画・音声を会議タブで再生する。
- 素材には「A案は100万円で2週間」「B案は80万円で4週間」、懸念、比較、質問、「決定は次回」、後半の「A案を採用」を含める。
- T4用の決定発言が利用者との相談中に流れるようにする。会議内の質問と利用者の質問は別の経路から入力する。

## 実施

| ID | 手順 | 確認する結果 |
|---|---|---|
| T1 | 案の説明が会議記録に届いたら、「どう思う？」と音声で相談する。 | 説明された案に即した見解である。事実と解釈を区別できる。 |
| T2 | 「なぜ？」「前の案と比べて？」と続ける。 | 説明を再入力せず、相談の文脈と比較対象を保てる。 |
| T3 | 「B案は2週間でできるんだよね」と誤った理解を伝える。 | 原発言を根拠に訂正・異なる見方を示せる。 |
| T4 | 相談中に会議側で「A案を採用」を流し、文字起こしが届いてから新しい決定を質問する。 | 相談中の発言が録音・文字起こしに残り、後から確認できる。音声を保存し原素材と区間を照合する。 |
| T5 | 会議側の決定、利用者の提案、AIの別案を含めて記録を書き出す。 | JSONのsegmentsに相談の発言がなく、consultationsに利用者とAIの相談が保存される。 |
| T6 | 会議内の「どう思いますか？」を静かな同席状態で流す。対話を開始・終了する。 | 会議内の質問には自動応答しない。対話終了後も会議録音が続く。 |
| T7 | AIの回答途中で「ちょっと待って、費用の話だけ聞きたい」と話す。 | 応答音声が止まり、新しい問いに応答する。停止までの時間を測定する。 |
| T8 | 直近30区間より古い発言を尋ね、記録にない承認者も尋ねる。 | 検索して原発言を参照でき、未確認の承認者を作らない。 |
| T9 | 記録と相談を終了し、ページを再読み込みする。同じ会議で「全体としてどうだった？」と音声で相談する。 | 保存記録を踏まえた振り返りと相談を続けられる。 |

## 結果として残す情報

- 実施日時、端末・ブラウザー、モデル、マイク・ヘッドホン・共有タブの設定。
- 各IDの合格／失敗／未実施、原発言の時刻、期待した動作、実際の動作。
- 会議発言から文字起こし到着まで、利用者の発話終了から応答開始まで、割り込み発話から音声停止までの実測時間。
- 元音声と保存WAVの区間照合、文字起こしの誤認識、相談音声やAI音声の会議録音への混入の有無。
- 不合格の再現手順と対応方針。結果をDEVELOPMENT_STATUS.mdへ反映する。
